A team knowledge base your AI agents can read and write

Every DumbSlab workspace has its own MCP server. Paste one URL into Claude, ChatGPT or Cursor, approve it in your browser, and your agents can search, read and edit the same docs your team uses.

Connect an agent in about a minute

  1. Create a free workspace. It gets its own address, such as acme.dumbslab.com.
  2. In Claude, ChatGPT or Cursor, add a custom connector with your workspace's MCP URL: https://acme.dumbslab.com/mcp. In Claude Code, run the command below.
  3. Approve access in the browser. The connection then shows under Settings › API tokens, where you can revoke it any time.
claude mcp add --transport http dumbslab https://acme.dumbslab.com/mcp

Clients without OAuth can send a personal access token from Settings › API tokens instead. Any client that speaks MCP over Streamable HTTP works.

What your agents can do

Everything a person can do in DumbSlab, an agent can do too. The web app runs on the same public API, so nothing is out of reach.

  • Search posts, comments and topics, with only what the person who connected it can see.
  • Read any post as Markdown, with its topic, history and comments.
  • Write new posts and topics, and comment on existing ones.
  • Edit precisely: replace one passage, or append to one section by its heading, instead of rewriting the whole doc.
  • Keep up with the activity feed, or have webhooks call your own agent when something changes.

The default toolset has about 15 everyday tools plus call_operation, which reaches every other operation. Add ?toolset=read to the URL for a connection that can only read.

Built so agents can't clobber your team's work

  • Conflicts, not overwrites. An agent sends the version it last read. If a teammate saved since then, the edit is refused with a conflict instead of erasing their change.
  • Every save is a version. Compare any two versions of a doc and restore any of them.
  • A name on every change. Give each agent its own bot account. Its edits show in history and activity under its name, marked MCP, API or CLI.
  • Read-only when you want it. A read-only connection or token can search and read, and nothing else.

Questions

What is an MCP knowledge base?

A knowledge base that AI tools can use through the Model Context Protocol (MCP), the open standard Claude, ChatGPT, Cursor and other assistants use to reach outside tools. Instead of pasting docs into a chat, the assistant searches and reads your team's docs itself, and can write and update them too.

Which AI tools work with DumbSlab?

Any MCP client. Claude, ChatGPT, Cursor and other clients that support OAuth need only your workspace's MCP URL, and you approve access in the browser. Other tools can use a personal access token with the MCP server or the REST API.

Can an agent see private topics?

Only if the person who connected it can. An agent acts with that person's access, so private topics, drafts and admin-only settings stay out of its reach unless they are in that person's. Give an agent its own bot account to decide exactly what it can see.

Is it free?

Yes. The MCP server, the API and webhooks are on the free plan, with every other feature. The free plan limits only storage and daily database writes; Pro raises them for $8 a month.
