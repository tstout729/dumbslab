If your team counts on verified answers, DumbSlab keeps that habit: mark a doc verified for a set time, see what's going stale, and find answers from Slack. Bring your Guru collections over in one import.

Verified knowledge, without the busywork

  • Verification. Mark any doc verified for a set number of days. When that time runs out, it shows as expired.
  • Insights. Stale and expired docs are listed in one place, so you know what to review next.
  • History. Every save is a version. Compare any two and restore any of them.
  • Comments. Comment on a whole doc or one highlighted passage, mention the right person, and resolve the thread when it's fixed.

Answers where people already are

  • Slack. /dumbslab search finds answers without leaving Slack, /dumbslab new starts a post, and links to posts everyone can see show a preview.
  • Search. Press ⌘K anywhere for full-text search across posts, comments and topics, plus each person's connected apps.
  • AI assistants. Every workspace has its own MCP server, so Claude, ChatGPT and Cursor can look things up in your docs and help keep them current.

How the Guru import works

  1. In Guru, open Manage › Collection Settings, then the ⋯ menu, then Export Collection. Guru emails you a zip.
  2. In DumbSlab, open Settings › Import and choose the zip. Your browser converts the cards to Markdown and shows a preview first.
  3. Choose Import, then read the report of what came across.

Questions

Does verification carry over from Guru?

No. Guru's export doesn't include verification state or owners, so imported posts start unverified. Verify them as you review them; Insights lists what's still waiting.

Can people search from Slack?

Yes. Add the Slack app, then use /dumbslab search to find posts and /dumbslab new to start one, as yourself. Links to posts that everyone can see show a preview in Slack.

Is DumbSlab free?

Yes. Every feature is free, including verification, the Slack app, single sign-on and the MCP server. The free plan limits only storage and daily database writes; Pro raises them for $8 a month.

Can we keep some collections private?

Yes. Create a private topic first and import into it. Topics the import creates inside a private topic are private too, with the same members.
