An open-source team wiki you can run yourself

DumbSlab is one Rust binary and one SQLite file. Run it on a laptop, a small server or Cloudflare Workers, with every feature and no limits, under the MIT or Apache-2.0 license.

Run it in a minute

With Rust 1.88 or newer:

git clone https://github.com/tstout729/dumbslab
cd dumbslab
cargo install --path crates/server
dumbslab serve

Or with Docker:

docker build -t dumbslab .
docker run -p 127.0.0.1:8080:8080 -v dumbslab:/data dumbslab

On first run the server logs a one-time setup link. Open it to create the admin account, and a Getting Started topic is waiting inside.

Dumb on purpose

  • One binary, one file. No separate database server, queue or search cluster. Search runs on SQLite's full-text index.
  • Nothing phones home. Session recordings and error reports stay off unless you set them, so a self-hosted server sends nothing anywhere.
  • Every feature. Posts, topics, search, history, verification, comments, roles and private topics, imports, webhooks and JSON export.
  • Agents included. The MCP server is at /mcp on your own host, with OAuth, and local agents can use stdio: dumbslab mcp --as you@example.com.
  • Your sign-in. Single sign-on with Google Workspace, Microsoft Entra ID, Okta, OneLogin, Slack or any OpenID Connect provider, using your own app.

Or deploy it to Cloudflare

The same code runs as a Cloudflare Worker, where each workspace is its own SQLite-backed Durable Object. Run one private workspace for your company, or a hosted service anyone can sign up for, which is how dumbslab.com runs. The Cloudflare guide covers the setup.

Questions

What does DumbSlab need to run?

Rust 1.88 or newer to build it, or Docker. It then runs as one binary with one SQLite file, so a small server or a laptop is enough for a team.

Does a self-hosted server send data anywhere?

No. Session recordings and error reports are off unless you configure them, and connected apps, Slack and single sign-on only talk to the services you set up.

Is there a user limit?

No. Self-hosted DumbSlab has no plans and no limits beyond your own server's.

What license is it under?

DumbSlab is dual-licensed under MIT or Apache-2.0, so you can read it, fork it and host it for your company.

Rather not run a server?

dumbslab.com hosts the same software for free. Create a workspace in about a minute.
