A free Confluence alternative that brings your spaces with you

DumbSlab is a simple, fast team wiki: Markdown docs, nested topics, search and history, free for your whole team. Bring your Confluence spaces over from their HTML export, and your AI agents can work in them on day one.

Why teams move to DumbSlab

  • Writing is simple. Markdown with a live preview, callouts, tables, checklists and toggles, plus embeds from about 30 services such as Loom, Figma and Google Docs.
  • Finding is fast. Full-text search across posts, comments and topics from anywhere with ⌘K, and search across connected apps such as Jira and GitHub.
  • Docs stay current. Mark a doc verified for a set time, and stale or expired docs show up in Insights for review.
  • Every feature is free. Single sign-on, the API, webhooks and uploads are on the free plan. Pro only adds room.
  • Agents are first-class. Every workspace has its own MCP server, so Claude, ChatGPT and Cursor can search and edit alongside your team.
  • It's open source. Use the free hosted service, or run it yourself under the MIT or Apache-2.0 license.

How the Confluence import works

  1. Export the space as HTML. In Confluence Cloud: Space settings › Export space › HTML. In Data Center: Space tools › Content tools › Export › HTML. Download the zip.
  2. In DumbSlab, open Settings › Import and choose the zip. Your browser converts every page to Markdown; nothing is sent yet.
  3. Check the preview: how many pages, topics and attachments there are, what will be skipped and why, and what the import needs from your plan. You can rename the top topic or import everything as drafts.
  4. Choose Import. The report lists what came across, what was already there and anything that failed.

You can run the same import again at any time. Pages that are already there aren't duplicated, and anything they still lack, such as an image that failed to upload, is added.

Headings, lists, tables, code blocks with their language and embedded videos come across too. Confluence's HTML export has no comments, page history or blog posts, so the import doesn't either, and page permissions don't carry over: import into a private topic to keep a space private.

Let an agent do the migration

Many teams migrate with an AI agent. Through MCP or the REST API, an agent can read an export, convert each page, import pages in batches with import_documents, upload their files and fix the links between them. The import guide has the steps.

Questions

Is DumbSlab really free?

Yes. Every feature is free at dumbslab.com, with no credit card and no trial, including single sign-on, the MCP server and the API. The free plan limits only storage and daily database writes. Pro raises them for $8 a month.

Does it work with Confluence Data Center?

Yes. Export the space as HTML from Space tools › Content tools › Export › HTML and import the zip the same way as a Confluence Cloud export. Confluence's XML export isn't supported.

Do comments and page history come across?

No. Confluence's HTML export doesn't include comments, page history or blog posts. In DumbSlab, every save from then on is a version you can compare and restore.

What about a large space?

A zip can be up to 1 GB and 200,000 files. If an import reaches the free plan's daily write limit, it stops; run it again once the allowance refills and it continues where it stopped. Or upgrade to Pro for more room.
