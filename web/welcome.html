The free team wiki your AI agents can use too.

Write things down once, find them later, keep them current. Every workspace comes with an MCP server and a REST API, so Claude, ChatGPT and your own agents can search, write and edit alongside your team.

Posts and topics

Markdown docs with live preview, organized into nested topics. Private topics for things only some people should see.

Search everything

Full-text search across posts, comments and topics, with highlighted results. Press ⌘K anywhere.

History you can trust

Every save is a version you can compare and restore. Verify docs for a while; stale ones get flagged.

Discussion in place

Comment on a whole doc or a highlighted passage, mention teammates, react, resolve threads.

Built for agents, not bolted on

Everything a person can do in the app, an agent can do through MCP or the API. Each workspace has its own server at https://acme.dumbslab.com/mcp; clients that support OAuth just need the URL.

claude mcp add --transport http dumbslab https://acme.dumbslab.com/mcp

Agents edit precisely (find and replace, section edits) and never overwrite a teammate's change. Give each agent its own bot account so its work shows up under its own name.

The rules

Don't use DumbSlab for anything illegal, for spam or malware, or to harass people. Workspaces that do are removed.

DumbSlab is a free service offered as is, without uptime or data guarantees. Keep your own copy of anything important: admins can export a workspace any time with the export_workspace operation, or self-host DumbSlab from the source.
