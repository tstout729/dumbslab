Built for agents, not bolted on

Everything a person can do in DumbSlab, an agent can do through MCP or the REST API. The web app runs on the same public API, so nothing is out of an agent's reach.

Claude Code

$ claude mcp add --transport http dumbslab https://acme.dumbslab.com/mcp

Claude, ChatGPT or Cursor: add a custom connector with this URL

https://acme.dumbslab.com/mcp

  • Sign in with OAuth

    Clients that support OAuth need only the URL. You approve access in the browser and can revoke it any time in Settings.

  • Edits that don't clobber

    Agents find and replace a passage or change one section by its heading. An edit made against an old version gets a conflict, not your teammate's work.

  • A name on every change

    Give each agent its own bot account. Its edits show in history and activity under its name, marked MCP, API or CLI.

  • Documented for machines

    Typed tool schemas with read-only hints, an OpenAPI 3.1 spec, signed webhooks, and an agent guide at /llms.txt in every workspace.

Everything a team wiki needs

The parts people use every day, with nothing that only works for people.

Posts and topics
Markdown docs with live preview, organized into nested topics. Drafts, templates and pinned posts.
Search
Full-text search across posts, comments and topics, with highlighted matches. Press ⌘K anywhere.
History
Every save is a version. Compare any two, and restore any of them.
Verification
Mark a doc verified for a set time. Stale and expired docs show up in Insights, so you know what to review.
Comments
Comment on a whole doc or one highlighted passage. Mention teammates, react and resolve threads.
Embeds and files
Upload images and files, or paste a YouTube, Loom, Google Docs, Figma, Canva or Typeform link to embed it.
Roles and private topics
Admins, members and viewers. Private topics for the things only some people should see.
Follows and notifications
Follow posts and topics to hear about mentions, replies and new posts.
Import and export
Bring Markdown files in all at once. Download the whole workspace as JSON whenever you like.

Dumb on purpose

DumbSlab is one Rust binary and one SQLite file. Run it on a laptop or a small server, or deploy it to Cloudflare Workers, where each workspace gets its own database. The code is MIT or Apache-2.0, so you can read it, fork it or host it for your company.

Questions

Is DumbSlab free?

Yes. Every feature is free at dumbslab.com, with no credit card and no trial; the free plan limits only storage and daily writes (see Pricing). The code is open source, so you can also run your own copy.

Which AI tools work with DumbSlab?

Any MCP client. Claude, ChatGPT, Cursor and other clients that support OAuth need only your workspace's MCP URL, such as https://acme.dumbslab.com/mcp, and you approve access in the browser. Other tools can use a personal access token with the MCP server or the REST API.

Can an agent overwrite my team's work?

Not by accident. Agents change one section or one passage at a time instead of rewriting the whole doc, and they send the version they last read. If a teammate saved since then, the edit is refused with a conflict instead of erasing their change. Every save is a version you can compare and restore.

Who can see my workspace?

Only the people you add. Admins add people and choose each person's role: admin, member or viewer. Private topics are visible only to their members, and drafts only to their author. Search engines are told to stay out of workspaces.

Can I change my address later?

Yes. Admins can move the workspace to a new address in Settings. Anyone who opens the old address in a browser is sent to the new one; AI tools need the new MCP URL.

Can I get my data out?

Yes. Posts are Markdown, and an admin can download the whole workspace as JSON at any time from Settings. You can bring Markdown files in, too.

Can I self-host DumbSlab?

Yes. It's one Rust binary and one SQLite file, or a Cloudflare Worker with a separate database for each workspace. The source is on GitHub under the MIT or Apache-2.0 license.

The rules

Don't use DumbSlab for anything illegal, for spam or malware, or to harass people. Workspaces that do are removed.

DumbSlab is a free service offered as is, without uptime or data guarantees. Keep your own copy of anything important: admins can download a workspace's export any time from Settings, or self-host DumbSlab from the source.
